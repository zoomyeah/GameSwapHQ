For Developers

Want your game on GameSwapHQ?

GameSwapHQ is a curated gaming portal. Every game is reviewed before being added to the site.

Game requirements

  • The game must be clean and appropriate for kids.
  • The game should be complete and playable.
  • The game should be good quality and reasonably polished.
  • The game must not contain inappropriate, offensive, or unsafe content.
  • The game should not contain unmoderated chat or other unsafe communication features.
  • The game should not attempt to collect personal information from players.
  • The game should not contain inappropriate advertisements or external content.
  • Games are reviewed manually before they are added to GameSwapHQ.

What happens after you submit?

Submit your game using the form below. Your game will be reviewed manually. If it meets the GameSwapHQ requirements, it can be added to the site.
